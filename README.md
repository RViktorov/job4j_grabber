## В этом репозитории размещен проект - Агрегатор вакансий.

Описание.
Программа считывает все вакансии c сайта career.habr.com (с первых 5 страниц
раздела https://career.habr.com/vacancies/java_developer),
относящиеся к Java и записывать их в базу.
Система запускается по расписанию - раз в минуту. Период запуска указывается в настройках - app.properties.
В проект можно добавить новые сайты без изменения кода. В проекте можно сделать параллельный парсинг сайтов.
